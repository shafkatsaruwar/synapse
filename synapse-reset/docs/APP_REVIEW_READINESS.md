# App Review readiness

This checklist records the repository changes made from the Apple review checklist in `App Launchpad - APPLE.pdf`.

## Implemented in the app

- The optional Supabase account path now has a **Delete Account** action under Privacy & Data. It invokes `supabase/functions/delete-account`, removes caregiver rows, deletes the Auth user, clears local data, and signs out.
- Medication check-in notifications now use the medication's actual cadence, cancel every prior missed-medication check-in before recalculating, and schedule at most one same-day reminder. Taking the last dose therefore removes the stale alert instead of leaving future alerts in the notification center.
- Appearance Studio reads the native iOS icon on entry and only confirms the new selection after iOS reports success. The bundled icon choices use real asset-catalog entries; unavailable artwork is reported instead of using a color-filtered substitute.
- Privacy, Terms, and Support links point to the public Synapse web routes used by the app and paywall.
- Apple sign-in is enabled in the Expo configuration and the iOS entitlement is present.

## Required Supabase deployment step

Deploy the account-deletion function before submitting a build:

```bash
supabase functions deploy delete-account --project-ref gnetrxuxrzzaifyasyst
```

The function uses the standard Supabase `SUPABASE_URL`, `SUPABASE_ANON_KEY`, and `SUPABASE_SERVICE_ROLE_KEY` function secrets. It does not accept a user id from the client.

## Remaining App Store Connect work

- Complete App Privacy answers from the final production data flows.
- Add the final support contact, review notes, screenshots, age rating, and export-compliance answers in App Store Connect.
- Test at least one clean install and one upgrade from the previous release on a physical iPhone. Verify purchases with Sandbox products and verify Restore Purchases.
- Verify the deployed `delete-account` function with a sandbox account and confirm the account and cloud backup are gone.
- The repository currently contains finalized assets for 12 icon variants. The missing source files are `Ocean-Dark.png`, `Amber-Dark.png`, `Rose-Dark.png`, and `Lavender-Light.png` under `assets/app-icons/`. They must be supplied before claiming a complete 16-icon picker; no replacement artwork is generated by the app.
